# AI Usage Report

## Introduction

AI tools were used as supplementary resources during the development of this personal portfolio website. Their purpose was to support learning, assist with debugging, and improve the understanding of React and JavaScript concepts, as well as help with writing documentation.

## AI Tools Used

**Tool: ChatGPT**

ChatGPT was used to ask questions about React components, JavaScript functionality, API integration, troubleshooting, and documentation. It served as a learning and problem-solving aid rather than a replacement for understanding the code.

**Tool: GitHub Copilot**

Copilot was used for code completion and suggesting code structures for certain functions, as well as reducing repetitive coding tasks (for example, writing multiple similar HTML elements).

## Areas of AI Assistance

### React Components

AI assistance was used to understand how React components are organized and how data and functions can be passed between components.

### State and Effects

Questions were asked about React's `useState` and `useEffect` hooks, particularly how component state is managed and how date and time information can be updated.

### API Integration

AI assistance was used to understand how external APIs work, how to retrieve GitHub repositories, how to use JokeAPI, and how to handle API responses, loading states, and errors.

### Debugging and Problem-Solving

AI assistance helped investigate programming issues and explain possible solutions. Suggestions were reviewed against the project's requirements before being used.

### Styling and User Interface

AI helped suggest some styles for designing interactive elements, such as buttons and hover effects on boxes.

### Performance Optimization

AI assistance was used to understand possible ways to improve website performance, including image compression, removing unused code, reducing repetition, and testing with Lighthouse.

### Documentation

AI assistance was used to help write and organize project documentation, including the README, AI Usage Report, Academic Integrity Report, and Technical Documentation.

## Benefits and Challenges

AI tools helped save time when researching React concepts, understanding unfamiliar functionality, and identifying possible solutions to programming problems.

However, some suggestions required further review because they did not always match the existing project structure or requirements. Therefore, AI-generated suggestions were not accepted without consideration and verification.

## Review and Adaptation of AI Suggestions

AI-generated suggestions were treated as guidance rather than automatically accepted solutions. Relevant suggestions were reviewed and adapted to fit the project's existing structure and requirements.

The goal was to understand why each solution works and how it affects the application. Changes were also tested to ensure that the implemented functionality worked as expected.

## Limitations

AI-generated responses may contain incorrect assumptions or code that does not match the project's environment. Therefore, AI assistance does not replace testing, debugging, or independent verification.

## Learning Outcomes

Using AI as a supplementary learning tool helped reinforce concepts related to React components, state management, effects, API integration, and application performance.

The development process also emphasized the importance of reviewing suggested solutions, understanding the resulting code, and documenting the use of AI transparently.
